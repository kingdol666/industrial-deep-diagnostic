## 4. Issues

### MUST-FIX
None. Every load-bearing number I checked (≥10 independent verifications, including a from-scratch
recompute of the keyword-sensitivity scenario with the grader's own matching logic) traces exactly to
the released artifacts, and the paper's self-limiting statements (bare-LLM 9/9, single execution,
author-designed instruments, IDV3 miss) are all accurate.

### SHOULD-FIX
1. **§5 Execution form (p.28)**: "the event logs record this per run" overstates coverage — only 7/12 canonical run directories carry an explicit inline marker (6 with `harness_mode` variants + the SKAB-valve run with `inline_execution:true`); skab_cavitation_13, skab_normal_control, tep_d00, tep_d01 and tep_d14 logs carry neither field (verified across event log, run_config.json, run_summary.json). State the coverage count explicitly; the disclosure is otherwise verbatim-accurate for the exemplar it names.

3. **Table 7 CI convention**: two proportion rows (honest capped verdicts 3/9; ceiling compliance 9/9) print no CI while the stated convention is "proportions carry Wilson 95% CIs"; add them or mark the rows as counts.
4. **Fig 3(b)/Fig 7 in-panel font size**: ~6 pt at print width; nudge up for print legibility.
5. **§8.3 Table 9 "Single-LLM, controls (GLM) … 2/2"**: the scope note is in the running text and Fig 8 caption; repeat "(TEP control not run)" inside the table row to prevent the 2/2 being read as 3/3-coverage.
