## 4. Issues

### MUST-FIX (blocking, small)
1. **Fig 3 (p-38, §6.1)**: printed per-dataset fractions (5/6, 0/2, 1/1) appear with no pre-revision
   keyword qualifier in the figure or caption, while every other headline surface (abstract, §1,
   Table 4, Table 7 caption, Figs 6/7 captions, §8, §9) carries 5/9 and 4/6. Under the pre-revision
   set the TEP bar is 4/6. One caption clause fixes it.
2. **§6.2 Metrics + Table 7 + Fig 7 "top-k (k=3)"**: the implemented quantity is keyword-membership
   over the *surviving-hypothesis set* (`zcode_direct_pipeline.mjs:386-387` grades survivors only),
   which is a single hypothesis for every DETERMINED case — there top-k is arithmetically identical to
   Top-1, and no ranked top-3 list exists. The paper's justification ("the protocol mandates at least
   three generated hypotheses") describes generation, not the graded survivor set. Define the metric
   precisely (e.g. "true-mechanism keyword in any surviving hypothesis") or rename; 8/9 is a headline
   number in Table 7 and Fig 7 and is currently generous relative to its name.
3. **Table 7 "Determined-verdict precision 6/6"**: the denominator conditions on the pipeline's own
   verdict choice — the gates force the caps, so which scenarios enter the precision calculation is
   selected by design. The caption notes non-independence with Top-1 but not this conditioning; add
   one clause (precision over self-selected DETERMINED verdicts under enforced caps).

### SHOULD-FIX (non-blocking)
1. §5 Execution form: "a dedicated field on eight runs" is convention-dependent — tep_d00 carries
   `harness:"inline-degraded"` on every agent_start *plus* a note, so 8+3 vs 9+2 depends on
   classification; state the counting convention (the headline 11/12 and the cavitation exception are robust).
2. §6.2 already flags that the IndPenSim keyword set contains the generic token "deviation"; consider
   releasing (or footnoting) the batch-093 outcome under the strict subset without it — one keyword row
   would fully future-proof the headline.
3. Fig 7 (p-47): grey sublabels ("n = 11 · candidates in prompt") collide with the 50% gridline and CI
   whiskers; nudge labels or add a white halo.
4. Fig 3(b): judge markers at exactly 90 (SKAB valve, IDV7) sit on the dotted "gate 90" line and read
   as ambiguous at print size; a half-offset or annotation would help.
