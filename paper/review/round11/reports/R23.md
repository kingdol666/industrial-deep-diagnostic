- Top-aligned float pages: **pass** — `\@fptop=0pt` works; all float-only pages (p16, p17, p42, p70, p71) start at the top text margin; no vertically-centred float page found.
- **Near-empty page: FAIL at p41** — exactly 3 lines of text ("to faults; the normal TEP run exhibits …") and ~90 % blank, stranded immediately before Table 7's float page (p42).
