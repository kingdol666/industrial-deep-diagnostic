## 2. Blocking defects

**B1 — Fig. 3(a) caption contradicts the drawn colours (p.34; main.tex:445).**
Caption: "Top-1-correct DETERMINED verdicts (blue), scenarios where the true mechanism is ranked … capped COMPETING_SET (amber), and the single mechanism-level miss (grey)." As drawn: the ranked-but-capped SKAB bar is **sky** (86,180,233), the miss (TEP IDV3 unit) is **amber** (230,159,0), and **no grey segment exists anywhere in panel (a)**. `make_figures.py:112–118` confirms the draw follows the Fig. 8 convention and adds in-code labels "capped CS, true mechanism ranked (top-k)" / "capped CS, true mechanism not ranked". The caption names the wrong hue for both non-blue classes. This is the headline results figure; a reader mapping caption→colours reads the paper's one miss as "grey" and finds nothing grey. **Fix (one line):** rewrite the caption to the drawn scheme: blue = Top-1-correct DETERMINED; sky = capped COMPETING_SET with the true mechanism ranked (the entire SKAB bar, printed 0/2); amber = capped COMPETING_SET without the true mechanism ranked (TEP IDV3).

**B2 — Fig. 4 colour system off-convention and caption factually wrong (p.37; main.tex:492; `make_figures.py:169–178`).**
Caption: "Amber bars mark the three COMPETING_SET verdicts whose confidence is capped at 0.58–0.65." As drawn (pixel scan of all 12 bars): only IDV3 (CS 0.60) is amber; SKAB valve (CS 0.65) and SKAB cavitation (CS 0.58) are **sky — pixel-identical to the five TEP DETERMINED bars** (all 86,180,233; script line 176: `base = BLUE if skab else SKY if tep else GREEN` encodes dataset, not verdict). Consequently (i) the caption is false for 2 of the 3 capped verdicts, and (ii) within one figure the same hue means both "DETERMINED fault" and "capped COMPETING_SET with mechanism ranked", which is exactly the distinction the paper sells. "Blue and green bars are DETERMINED fault verdicts" is also imprecise (TEP DET bars are sky; green marks only the IndPenSim fault, unexplained). **Fix:** recolour `fig_calibration` to the convention (dark blue = DETERMINED faults, sky = capped CS ranked, amber = capped CS unranked, grey hatch = controls — the hatch/ceiling-line annotations stay) and correct the caption; this requires only a palette change in `make_figures.py` and a rebuild.

**B3 — Under-filled appendix float pages (pp.67–68; main.tex:659, 683).**
Table A1 shares its page with nothing: ~38% of the page blank above the caption and ~30% blank below. Table A2 likewise (~25% above, ~20% below). Cause: `[!htbp]` — the `!` bypasses the paper's own `\floatpagefraction=0.85` discipline (main.tex:37). This violates basic AEI appendix layout ("no half-empty float pages"). **Fix:** drop the `!` (use `[t]` so text flows around/below), or set both appendix tables on one page, or let the Data-availability/back-matter text precede them.

## 6. Verdict rationale

The quantitative layer is exemplary — every printed number across seven figures and ten tables reconciles with released artifacts, and the Okabe–Ito palette is colour-blind-safe, vector, and consistently declared. What blocks publication as-is is that the two most-viewed result figures carry captions that describe a colour scheme different from the one printed (Fig. 3a) or a verdict-hue mapping the figure does not implement (Fig. 4), plus broken appendix float pages. All three are mechanical fixes (two captions, one palette change, one float option) requiring no re-execution — hence minor revision.
