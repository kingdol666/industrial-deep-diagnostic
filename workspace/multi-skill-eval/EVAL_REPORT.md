**交叉验证价值**：两个系统在水泥数据上**独立检出了一致的劣化事实**（强度单调下行/趋势混杂/换源混杂），但一个回答"为什么"（介质级配，物理域），一个回答"调什么"（参数窗+确认试验，参数域）——互为印证且互补：诊断的 P0（补球）执行后，正需要 doe-analyzer 在新工况上重建操作窗口。

## 四、选用建议

- 出了问题找根因 → **诊断流程**（物理机制 + 竞争假设，深度无可替代）
- 日常寻优/调参参考/工况画像 → **doe-analyzer**（快 5-8 倍、确定性门禁、机器可读合同直达下游 agent）
- 二者串成闭环：诊断 P0 → 新工况数据 → doe-analyzer 窗口 → 确认试验 → 窗口转正 → monitor 模式守稳（二期）
