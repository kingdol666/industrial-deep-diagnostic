# 参数代号对照说明（填写示例）

> 本文件说明数据表表头代号的命名规则与含义。**代号是本厂/产线内部命名，外部无法直接理解，
> 因此这份对照说明是必附文件**；产线请按同样格式维护自己的代号表（可另存为 json/csv 供系统读取，
> 见 `03_映射文档/tag_mapping.json` 的字段结构）。

## 命名规则

`L3-<设备节点>-<侧别/部位>-<功能>-<序号>`，例如：

- `L3-TDO-N-ST-Z4-TE01` = L3线 / 横拉机TDO / 北侧N / 拉伸区ST / 第4分区Z4 / 温度TE / 编号01
- `L3-FL-DP01` = L3线 / 熔体过滤器FL / 压差DP / 编号01
- 常用功能码：TE=温度、PT/DP=压力/压差、FQ=流量、SPD=速度、TN=张力、CUR/I=电流、
  HOUT=加热输出(%)、FAN-HZ=风机频率、W=宽度、SP=设定值(SetPoint)、OUT=闭环输出

## 代号明细（按设备节点分组）

### L3-DRY 干燥系统（切片预结晶与干燥除湿，控制切片含水率）

- `L3-DRY-DP-TE01` = 干燥塔露点温度（℃，回路 AI-1101，正常范围 -62.0~-58.0℃）：切片干燥塔出口空气露点，反映切片含水控制水平；露点劣化会把水分带进熔体
- `L3-DRY-RG-TE01` = 再生风加热温度（℃，回路 TIC-1102，正常范围 172.0~178.0℃）：干燥塔再生风加热器出口温度，决定除湿能力

### L3-EX 主挤出机（PET 切片熔融、计量泵送熔体）

- `L3-EX-MGT-TE01` = 主挤出机计量段温度（℃，回路 TIC-1201，正常范围 281.0~283.2℃）：计量段熔体温度，决定熔体粘度与泵送稳定性
- `L3-EX-PT01` = 熔体压力（模头前）（bar，回路 PIC-1202，正常范围 107.0~113.5bar）：模头前熔体压力，反映计量泵输送与管路阻力状态
- `L3-EX-CUR01` = 主挤出机电流（A，回路 II-1203，正常范围 205.0~218.0A）：主挤出机螺杆驱动电流，与扭矩/熔体粘度同向
- `L3-EX-SPD01` = 主挤出机螺杆转速（rpm，回路 SI-1204，正常范围 62.0~64.0rpm）：主挤出机转速，与铸片厚度基准成正比

### L3-FL 熔体过滤器（过滤熔体杂质（滤网随运行堵塞，需定期换网））

- `L3-FL-DP01` = 熔体过滤器压差（bar，回路 PDI-1205，正常范围 0.5~2.5bar）：熔体过滤器进出口压差，随时间锯齿上升，换网后复位；是滤网寿命直接指标

### L3-DIE 模头（熔体分配到设定宽度与厚度）

- `L3-DIE-TE01` = 模头温度（℃，回路 TIC-1301，正常范围 284.3~285.8℃）：模头区熔体温度，影响模口出膜厚度横向分布
- `L3-DIE-HOUT01` = 模头加热输出（%，回路 TIC-1301.OUT，正常范围 40.0~48.0%）（控制量，目标 44.0%）：模头加热器输出百分比（闭环输出量），长期偏高说明热损失/加热器老化

### L3-CR 铸片辊（急冷辊）（熔膜骤冷成铸片，控制预结晶度）

- `L3-CR-TE01` = 铸片辊表面温度（℃，回路 TIC-1401，正常范围 26.2~26.9℃）：急冷辊表面温度，决定预结晶度；过高会发雾、过低会粘辊
- `L3-CR-SPD01` = 铸片辊线速度（m/min，回路 SI-1405，正常范围 16.3~16.52m/min）：铸片线速，与挤出量共同决定铸片厚度基准
- `L3-CR-ES-V01` = 静电贴附电压（kV，回路 EI-1406，正常范围 6.8~7.3kV）（控制量，目标 7.0kV）：静电吸附电压，保证铸片与冷辊贴合（不足会产生横向厚度条纹）

### L3-MDO 纵拉机(MDO)（铸片预热后在 Tg 以上纵向拉伸并急冷定型）

- `L3-MDO-PH1-TE01` = 纵拉预热辊1温度（℃，回路 TIC-2101，正常范围 77.4~78.6℃）：预热段第1辊温度（接近 PET Tg≈78℃）
- `L3-MDO-PH2-TE01` = 纵拉预热辊2温度（℃，回路 TIC-2102，正常范围 78.4~79.6℃）：预热段第2辊温度
- `L3-MDO-PH3-TE01` = 纵拉预热辊3温度（℃，回路 TIC-2103，正常范围 79.4~80.6℃）：预热段第3辊温度
- `L3-MDO-ST1-TE01` = 纵拉拉伸辊1温度（℃，回路 TIC-2104，正常范围 85.8~87.2℃）：拉伸段第1辊温度（Tg 以上 8℃ 左右，保证均匀拉伸）
- `L3-MDO-ST2-TE01` = 纵拉拉伸辊2温度（℃，回路 TIC-2105，正常范围 86.4~87.8℃）：拉伸段第2辊温度
- `L3-MDO-AN-TE01` = 纵拉定型辊温度（℃，回路 TIC-2106，正常范围 33.6~36.4℃）：纵拉出口急冷定型辊温度
- `L3-MDO-V01` = 纵拉入口速度（m/min，回路 SI-2107，正常范围 16.32~16.52m/min）：纵拉慢辊线速度（拉伸入口）
- `L3-MDO-V02` = 纵拉出口速度（m/min，回路 SI-2108，正常范围 52.7~53.15m/min）：纵拉快辊线速度（拉伸出口）
- `L3-MDO-TQ01` = 纵拉机组扭矩（%，回路 JI-2109，正常范围 60.5~63.5%）：纵拉驱动扭矩，反映拉伸应力水平

### L3-TDO 横拉机(TDO)（纵拉片预热、横向拉伸（分区分侧热风）、热定型）

- `L3-TDO-S-PH-TE01` = TDO南侧预热区热风温度（℃，回路 TIC-2301S，正常范围 154.4~155.6℃）：横拉机南侧预热区热风温度
- `L3-TDO-N-ST-Z4-TE01` = TDO北侧拉伸区4区热风温度（℃，回路 TIC-2404N，正常范围 237.8~240.6℃）：横向拉伸主拉伸区（第4分区）北侧热风实际温度，决定该侧 PET 取向与横向厚度分布
- `L3-TDO-S-ST-Z4-TE01` = TDO南侧拉伸区4区热风温度（℃，回路 TIC-2404S，正常范围 239.6~240.4℃）：横向拉伸主拉伸区（第4分区）南侧热风实际温度
- `L3-TDO-N-AN-Z6-TE01` = TDO北侧定型区6区热风温度（℃，回路 TIC-2606N，正常范围 190.1~191.4℃）：定型区（第6分区）北侧热风温度，决定热收缩率与尺寸稳定性
- `L3-TDO-S-AN-Z6-TE01` = TDO南侧定型区6区热风温度（℃，回路 TIC-2606S，正常范围 190.7~191.3℃）：定型区（第6分区）南侧热风温度
- `L3-TDO-N-ST-Z4-SP01` = TDO北侧拉伸区4区温度设定值（℃，回路 TIC-2404N.SP，正常范围 240.0~240.0℃）（设定值恒定 240.0）：操作设定的北侧拉伸区温度目标值（本窗口内未调整，恒定 240.0）

## 批次号与状态码

- `L3-MES-BATCH01` 生产批次号：格式 `YYYYMMDD-A01`，12 小时一个批次（同一规格连续生产的分卷批次）
- `L3-MES-SPEC01` 产品规格代号：`GP12` = 12 μm 包装级光膜
- `L3-MES-RECYCLE01` 回料掺入比例：配方参数（%），本窗口 2026-09-27 08:00 由 8 调整为 12
- `L3-LINE-MODE01` 运行状态码：1=正常运行，2=升降速/换网，3=停机（本窗口无停机）

## 特殊说明

- 带 `SP01` 后缀的列是**设定值（SV）**，本窗口内恒定；带 `HOUT01/OUT` 的是**闭环输出百分比**，
  用于判断执行器是否需要“更费力”才能维持设定——输出持续上升是设备效能下降的重要线索
- 主表与化验表时间轴对齐（化验表时间点均落在主表 10 分钟网格上），系统可自动按时间合并
- 全部数值不带单位（单位见本说明或映射表），缺失值请留空单元格
