# 题目 S6 · 厚度超差根因诊断（9 阶段管线）

**目标 skill**：`industrial-analysis-auto`（端到端根因诊断编排器，Step 0-9）

## 场景

BOPET-1 线 12μm 光膜，10-01 ~ 10-10（240 个小时点）。10-06 前后起厚度超差报警增多、优品率走低。请按 9 阶段管线做完整根因诊断：数据体检 → 本体 → 处理 → 竞争假设诊断 → 评审 → 报告 → HTML。

## 数据与本体

- `00_input/thickness_fault_10d.csv`（240 行 × 15 列）：主挤计量段温度、熔体压力、**滤器压差**、模头温度、铸片辊温度、铸片辊线速、纵拉预热辊温、纵拉拉伸速度、TDO拉伸区温度CX4、TDO定型区温度CX6、TDO出口轨宽、牵引入口张力、薄膜厚度、优品率；
- `00_input/ontology.json` = 共享 BOPET 全线本体（14 信号 × 6 参数组、11 条机制边、4 个混杂因子）——参数名与数据列一一对应，`role=quality` 标记质量指标，`TDO拉伸区温度CX4→薄膜厚度/优品率`、`滤器压差→熔体压力/优品率` 为 causal 边；
- `00_input/user_context.md`：给诊断 agent 的用户语境（症状、时段、约束）。

## 判据（验收口径）

1. setup.mjs 生成合法 run 脚手架（run_manifest + run_config，mode=fast）；
2. inspect.mjs 流式解析通过（240 行、15 列、时间列识别、无抽样）；
3. 本体被 Step 2 消费（而非 auto 推断）：CX4/滤器压差两条 causal 链进入证据体系；
4. 诊断结论应能区分"CX4 缓漂（设备性）"与"滤器堵塞（工艺性）"两条竞争假设并按证据定级。
