# 题目 S5 · TDO 配方小试闭环寻优（目标驱动 DMTA）

**目标 skill**：`industrial-optimizer-loop`（闭环寻优：init → design → 执行 → ingest → converge）

## 场景

BOPET-1 线要在三因子域内找优品率最高的 TDO 配方：CX4 ∈ [235,245] ℃、纵拉拉伸速度 ∈ [50.9,54.9] m/min、CX6 ∈ [186,196] ℃，预算 ≤15 个设计点（R1 为 5 点 LHS，其后 GP-EI 每轮 1 点，确认轮带 3 次重复）。产线侧由"虚拟产线" `plant_simulator.py` 扮演执行与化验（回投 trial_result.json）——这是**演示替身**，真实部署时由产线/AWS 执行并回投。

## 契约文件

- `00_input/objective.json`：v1.0 目标契约（campaign OPT-20261014-001，goal=maximize 优品率，tolerance 0.3，安全约束 CX4≤245 硬限，seed=42）；
- 三因子名与本体 signal 名一致（`TDO拉伸区温度CX4 / 纵拉拉伸速度 / TDO定型区温度CX6`）。

## 调用

```bash
OPT=workspace/bopet-skill-eval/S5_optimizer_recipe
uv run --project .claude/shared/scripts python .claude/skills/industrial-optimizer-loop/scripts/optimizer.py init    --run-dir $OPT --objective $OPT/00_input/objective.json
uv run --project .claude/shared/scripts python .claude/skills/industrial-optimizer-loop/scripts/optimizer.py design  --run-dir $OPT          # R001（无先验→lhs_fill）
uv run --project .claude/shared/scripts python $OPT/plant_simulator.py --run-dir $OPT --round R001                            # 虚拟执行+回投
uv run --project .claude/shared/scripts python .claude/skills/industrial-optimizer-loop/scripts/optimizer.py ingest  --run-dir $OPT --result $OPT/02_rounds/R001/trial_result.json
# 重复 design→simulate→ingest 直到状态机进入终态（本夹具实测 R003 进确认、R004 收敛）：

uv run --project .claude/shared/scripts python .claude/skills/industrial-optimizer-loop/scripts/optimizer.py converge --run-dir $OPT
```

## 判据（验收口径）

1. init 过 O-G1 校验；R001 无先验冷启动布点成功（确定性 LHS）；
2. 每轮 design 产物 trial_design.json、ingest 后状态推进，无回投时 design 拒续并报 EXECUTION CONTRACT；
3. 3 轮后最优点明显优于 R001 起点（GP/EI 收敛方向正确）；
4. converge 输出结论与配方建议；全程无任何"参数下发"动作（只产布点）。
