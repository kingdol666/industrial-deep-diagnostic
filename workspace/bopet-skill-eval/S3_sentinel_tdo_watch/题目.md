# 题目 S3 · TDO 工段哨兵监控（基线 + 5 天监视窗）

**目标 skill**：`industrial-sentinel`（产线哨兵，watch 批筛模式）

## 场景

BOPET-1 线 TDO 工段已平稳运行至 10-10（10 天小时数据可作历史）。10-11 起连续 5 天的监视窗数据中，班组怀疑"定型区温度有缓慢爬升、熔体压力偶尔打尖"。请先用历史数据固化统计基线，再对监视窗做哨兵批筛，给出告警清单。

## 数据

- `00_input/tdo_history_10d.csv`（240 行 × 7 列，10-01 ~ 10-10）：熔体压力、铸片辊温度、纵拉预热辊温、TDO拉伸区温度CX4、TDO定型区温度CX6、牵引入口张力；
- `00_input/tdo_watch_5d.csv`（120 行 × 7 列，10-11 ~ 10-15）：同列集。

## 本体映射（哨兵不直接消费本体；操作窗先验可选 doe 产物）

本夹具不提供 doe 操作窗 → C2 漂移投影按哨兵自身的稳态斜率通道工作，缺 doe 先验会在告警中如实降级披露；列级物理语义见共享本体（`CX6=定型区热定型温度、熔体压力=滤器下游压力`）。

## 调用

```bash
# 1) 固化基线（≥100 稳态行/组）
uv run --project .claude/shared/scripts python \
  .claude/skills/industrial-sentinel/scripts/build_baseline.py \
  --history-csv workspace/bopet-skill-eval/S3_sentinel_tdo_watch/00_input/tdo_history_10d.csv \
  --out workspace/bopet-skill-eval/S3_sentinel_tdo_watch/baselines/watch_baseline.json

# 2) watch 批筛
uv run --project .claude/shared/scripts python \
  .claude/skills/industrial-sentinel/scripts/sentinel.py watch \
  --data workspace/bopet-skill-eval/S3_sentinel_tdo_watch/00_input/tdo_watch_5d.csv \
  --baseline workspace/bopet-skill-eval/S3_sentinel_tdo_watch/baselines/watch_baseline.json \
  --out-dir workspace/bopet-skill-eval/S3_sentinel_tdo_watch
# 产出 <out>/sentinel/alert.json + watch_report.md
```

## 判据（验收口径）

1. build_baseline exit 0（240 行全稳态，满足 ≥100）；
2. watch 检出 CX6 缓慢爬升（C2 漂移投影给出 hours_to_edge 与方向）与熔体压力尖峰（C1 Nelson R1 违规），且带告警合并/迟滞语义；
3. 无 doe 先验时 C2 相关通道的降级如实写入 alert/report；
4. exit 1（有发现）。
