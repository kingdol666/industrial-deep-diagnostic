# 题目 S2 · 纵拉(MDO)工艺窗口 DOE 分析

**目标 skill**：`industrial-doe-analyzer`（designed 模式）

## 场景

BOPET-1 线纵拉段（MDO）工艺摸底：预热辊温、拉伸速度、拉伸比三因子旋转中心复合设计（CCD, k=3, α=1.682），20 次试验已随机顺序执行完毕。目标：在雾度 ≤2.0%、厚度偏差 ≤30nm 约束下最大化拉伸强度，并给出可下试的操作窗。

## 数据

`00_input/mdo_ccd_trials.csv`（20 行 × 7 列）：试验顺序、预热辊温(℃)、拉伸速度(m/min)、拉伸比、拉伸强度(MPa)、雾度(%)、厚度偏差(nm)。

## 上下文映射（doe-analyzer 无本体耦合，等价物是 analysis_context.json）

`00_input/analysis_context.json`：三因子 numeric、三响应 goal/usl/target、run_order=试验顺序、assigned_by=user；本体中 `拉伸比→雾度(二次恶化)`、`纵拉预热辊温→拉伸强度` 的物理关系已写进共享本体（本 skill 不读本体，其 BH-FDR 相关链与本 context 的物理先验一致）。

## 调用

```bash
uv run --project .claude/shared/scripts python \
  .claude/skills/industrial-doe-analyzer/scripts/analyze.py all \
  --run-dir workspace/bopet-skill-eval/S2_doe_mdo_ccd \
  --data workspace/bopet-skill-eval/S2_doe_mdo_ccd/00_input/mdo_ccd_trials.csv
```

## 判据（验收口径）

1. 模式自检识别为 designed（CCD），非 observational 兜底；
2. ANOVA/BH-FDR 出显著主效应与二次项，响应面给出驻点；
3. `conclusions/recommendations.json` 产出操作窗（W1-W5），雾度约束真实起作用（高拉伸比端被排除）；
4. 确定性结论 B 级封顶、observational 类结论须 confirmation_needed（designed 不适用则不出现）。
