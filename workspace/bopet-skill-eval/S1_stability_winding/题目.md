# 题目 S1 · 收卷工段一周稳定性体检

**目标 skill**：`industrial-line-stability-report`（产线运行稳定性报告）

## 场景

BOPET-1 线收卷工段（牵引辊组→收卷机），12μm 光膜。近一周班报反映"厚度仪读数毛刺变多、卷端松紧不一"，请对该工段 10-01 ~ 10-07（168 个小时点）做一次稳定性体检，回答：稳不稳、差在哪、优先查什么。

## 数据

`00_input/winding_week.csv`（168 行 × 7 列，小时级，utf-8）：
牵引入口张力(N)、收卷锥度张力(%)、展平辊压力(bar)、收卷速度(m/min)、薄膜厚度(μm)、优品率(%)。

## 本体映射

`00_input/ontology.json` = 全线本体拷贝（收卷工段组 + 质量指标组生效）：
`牵引入口张力 → 牵引辊组张力（胡克弹性，张力波动→测厚扰动）`、`薄膜厚度/优品率 → 质量指标（带 normal_range 11.91–12.09μm / 96–100%）`；关系边 `牵引入口张力 →(causal,medium) 薄膜厚度`。

## 调用

```bash
uv run --project .claude/shared/scripts python \
  .claude/skills/industrial-line-stability-report/scripts/stability_analyzer.py analyze \
  --run-dir workspace/bopet-skill-eval/S1_stability_winding
# 之后 report_builder.py + quality_gate.mjs（见 skill 协议 Phase 2-3）
```

## 判据（验收口径）

1. exit 0/1，本体命中 `condition.ontology.mode=ontology`（非 auto）；
2. 牵引入口张力与薄膜厚度的相关性发现（若有）机制等级为 known（不再是 [MECHANISM_UNKNOWN]）；
3. 薄膜厚度获得用户规格限的 Cpk 分档；
4. 门禁 quality_gate exit 0。
