# 题目 S4 · 牵引段调参动作效果归因

**目标 skill**：`industrial-tuning-memory`（调优经验库，attribute 归因）

## 场景

BOPET-1 线 10-01 ~ 10-04（96 个小时点）期间工程师做了两次手动调参：10-02 16:00 提产（纵拉拉伸速度 52.9→53.4 m/min），10-03 16:00 热定型补偿（TDO CX4 240→242 ℃）。请用调优记忆的确定性归因回答：这两次动作对薄膜厚度各产生了多大、多可信的效果？

## 数据

- `00_input/data.csv`（96 行 × 4 列，小时级）：时间、纵拉拉伸速度、TDO拉伸区温度CX4、薄膜厚度(μm)；
- `00_input/action_log.json`：2 条 v1.0 动作日志（actor E-wang / E-li，manual 触发）。

## 参数名映射

动作日志 `parameter` 使用"×××设定"（设定值口径），数据列为实际值口径：`纵拉拉伸速度设定→纵拉拉伸速度`、`TDO拉伸区温度CX4设定→TDO拉伸区温度CX4`；归因目标 `--metric 薄膜厚度`（本体中 role=quality，normal_range 11.91–12.09μm）。经验库 `06_experience/` 为空库冷启动——归因输出即首批经验条目。

## 调用

```bash
uv run --project .claude/shared/scripts python \
  .claude/skills/industrial-tuning-memory/scripts/tune_stats.py attribute \
  --run-dir workspace/bopet-skill-eval/S4_tuning_traction \
  --time-col 时间 --metric 薄膜厚度 \
  --dead-time 6 --tau-steps 6 --settle-steps 24
```

两个已踩坑（出题实测）：① action_log 的 `ts` 必须带与数据一致的时区偏移（本夹具数据为本地朴素时间，ts 写 `+08:00`；写 `Z` 会被平移 8 行）；② `--settle-steps` 是效果窗视界（行数）而非过渡时长，缺省 200 会把效果窗截断降级 E0，需按工艺知识显式给死区/视界。

## 判据（验收口径）

1. 两个动作均 estimable（基线段 ≥10 点、效果段 ≥2 点），Δμm 估计与真值同量级；
2. 效果方向正确（提产→厚度下降；CX4 补偿→厚度部分回升）；
3. 防伪链字段齐全（Welch Δ、AR(1) 有效 n、死区/过渡段处理），不可估时给 reason_code 而非编造；
4. exit 0。
