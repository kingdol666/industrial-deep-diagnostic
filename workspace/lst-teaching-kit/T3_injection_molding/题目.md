# T3 · 注塑机逐模质量波动（JSON + spec_limits）

**学习点**：JSON 行对象数组格式 + report_context 的 spec_limits/inspection_cols 用法；以及"无本体时相关性只能是统计共变"。

## 场景

注塑 3 机生产家电 PP 外壳，QC 反映"单件重量忽大忽小、称重复检才合格"。对 09-08 06:00 起 30 小时的逐模记录（120 模）做稳定性体检。

## 数据

`00_input/shots_30h.json`：**行对象数组**（每模一个 JSON 对象）。保压压力(MPa)、熔体温度(℃)、锁模力(kN)、循环时间(s)、单件重量(g)。

## 已备好的映射文件

`00_input/report_context.json`：`inspection_cols: ["单件重量"]` 把重量标注为质检列；`spec_limits: 单件重量 24.7-25.3g` 启用 Cpk。注意 `time_col` 用的是"模次时间"——时间列名不叫"时间"时在 context 里显式指定（或用 `--time-col`）。

## 运行

与 T1 相同，run-dir 换成 `workspace/lst-teaching-kit/T3_injection_molding`。

## 报告看点

1. 保压压力应触发 SPC 违规（20 模周期振荡），单件重量同步波动（相关性 r≈0.98）；
2. 对比 T1：本题**没有 ontology.json**，相关性发现的机制等级是 `[MECHANISM_UNKNOWN]`、置信度封顶 45，结论只能写"统计共变、待机理确认"——理解本体的价值；
3. 讲解 JSON 读取约定：数组或"含数组的对象"均可，非表格 JSON 会报错。
