# T2 · 污水处理曝气池六天巡检（TSV，最简路径）

**学习点**：零配置路径——文件夹里只放一个数据文件（TSV），不写 report_context 也能出报告；以及"中文质检列需要 context 才能被正确标注"。

## 场景

污水厂生化池，运营方感觉"风机越来越吃力但 DO 上不去"。对 09-05 ~ 09-10（144 个小时点）做稳定性体检，确认溶解氧是否在走低。

## 数据

`00_input/aeration_6d.tsv`（制表符分隔）：溶解氧DO、鼓风机频率、MLSS浓度、进水COD、出水氨氮。

## 运行

与 T1 相同，把 run-dir 换成 `workspace/lst-teaching-kit/T2_wastewater_aeration`。

## 报告看点

1. DO 应触发**显著下漂**（相对漂移 >0.1%/天阈值），鼓风机频率对应上漂——讲解"漂移分档扣分只在 Theil-Sen+Mann-Kendall p<0.01 且相对漂移 ≥0.1%/天 时计入"（防噪声假漂移）；
2. 进水 COD 的昼夜周期会被 C3 工况分段识别出**显著变点**，报告发 `regime` 类发现"工况发生结构性切换"并提示分段解读——理解"周期不等于工况切换"，讲解如何结合工况分段表阅读；
3. 注意：**没有 context 时所有数值列默认按工艺参数评估**，"出水氨氮"这类质量列不会被自动识别为质检指标（自动识别只认英文关键词）——这正是"什么时候需要写 report_context"的活教材；
4. 讲解 TSV：自动按制表符读取，无需任何配置。
