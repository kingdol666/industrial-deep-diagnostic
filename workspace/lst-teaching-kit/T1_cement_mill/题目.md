# T1 · 水泥球磨机一周运行稳定性（XLSX + 本体 + 完整上下文）

**学习点**：完整示范路径——Excel 数据 + 手写本体 + report_context（规格限/权重/质检列）全量用法。

## 场景

水泥磨 2 线（P·O 42.5），中控发现"主轴承温度趋势向上、磨机电流比上月高 3A"。请对该磨机 09-01 ~ 09-08（180 个小时点）做稳定性体检。

## 数据

`00_input/mill_7d.xlsx`：磨机电流(A)、主轴承温度(℃)、入磨喂料量(t/h)、选粉机转速(rpm)、磨音(dB)、比表面积(cm²/g)、台时产量(t/h)。

## 已备好的映射文件（讲解重点）

- `00_input/ontology.json`：粉磨系统本体——`主轴承温度→(causal)磨机电流`、`选粉机转速→(causal)比表面积` 两条机制边；放入 `00_input/` 即被自动发现（`condition.ontology.mode=ontology`）；
- `00_input/report_context.json`：用户规格限（主轴承温度 USL 68℃、比表面积 3400-3600）+ 质量权重 ×2 + 质检列声明。

## 运行

```bash
cd <仓库根目录>
uv run --project .claude/shared/scripts python \
  .claude/skills/industrial-line-stability-report/scripts/stability_analyzer.py analyze \
  --run-dir workspace/lst-teaching-kit/T1_cement_mill
# 出 HTML 与门禁（Phase 2）：
uv run --project .claude/shared/scripts python \
  .claude/skills/industrial-line-stability-report/scripts/report_builder.py \
  --report workspace/lst-teaching-kit/T1_cement_mill/line_report/stability_report.json \
  --charts workspace/lst-teaching-kit/T1_cement_mill/line_report/charts.json \
  --out workspace/lst-teaching-kit/T1_cement_mill/line_report/line_stability_report.html
node .claude/skills/industrial-line-stability-report/scripts/quality_gate.mjs \
  workspace/lst-teaching-kit/T1_cement_mill/line_report/stability_report.json \
  workspace/lst-teaching-kit/T1_cement_mill/line_report
```

## 报告看点

1. 主轴承温度应触发**显著漂移**与规格越限相关发现，且与磨机电流的相关机制为 **known**（本体边）；
2. 比表面积获得用户规格限的 Cpk 分档；
3. 讲解 XLSX 读取：pandas + openpyxl，无需转 CSV。
