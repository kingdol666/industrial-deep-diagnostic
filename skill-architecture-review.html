Industrial Deep Diagnostic
端到端工业深度诊断管线

一个面向任意工业流程的多智能体根因诊断引擎。从传感器/工艺数据输入，经过 10 步管线 （本体构建 → 统计验证 → 竞争假说 → 物理验证 → 质量审查 → HTML 可视化）， 产出可信、可审计、可追溯的中文诊断报告与交互式可视化页面。

01 · CORE PHILOSOPHY

诊断是排除，不是确认

每个结论都必须满足四条件：时间先后 + 统计显著 + 物理机制 + 无矛盾。 缺任一项 → 标注 [HYPOTHESIS]。 数据无法区分竞争假说时 → 输出 COMPETING_SET，不猜测。

①
数据自描述
列名、值域、统计签名揭示工艺类型——无固定 taxonomy。不会把「CNC 模板」套到非 CNC 数据上。
②
RAG 语义理解
RAG 知识被语义 comprehend，不是机械 field-by-field 映射。提取物理原理、因果机制、失效模式。
③
第一性原理物理
每个统计相关必须追溯到主导方程；未知参数从守恒律、量纲分析、本构关系推导。
