# BC3 评分参考（出题人用）

## 真相

**DETERMINED：TDO 拉伸区南侧风温异常下降**（风门执行器卡涩或加热管组烧断）→ 南侧片材拉伸不足 → 出口宽度收窄 + 张力分布不均 → **操作侧（南侧）边部应力集中破膜**。置信度应 ≥90%。

## 注入的信号（时间线）

| 时间 | 事件 | 数据依据 |
|---|---|---|
| 09-08 06:00 | 南侧拉伸区风温 2h 阶跃 -6.5℃，随后 3 天缓降至合计 -10℃（240.5→230.5℃）；北侧与定型区两侧正常（温差从 ≤2℃ 扩大到 ~10℃） | `dcs_tdo_10min.csv` 南/北风温列 |
| +4h（τ） | 出口宽度 6329→~6320 mm | dcs 出口宽度 |
| +4h | 牵引张力均值 +15N、波动 std 8→22N | dcs 牵引入口张力 |
| +12h 起 | 破膜 0.3→2.2 次/班，位置 72% 集中在**操作侧**；优品率 98.6→97.1 | `qc_shift_8h.csv` |

生成参数见 `generation_manifest.json`（seed=103）。

## 关键判据（评分点）

1. **先后顺序**：温度不对称（09-08 06:00）**先于**宽度/张力/破膜变化，滞后量与热响应 τ 一致 → 因果方向成立。
2. **空间对应**：异常侧（南=操作侧）与破膜位置统计一致；若只报"破膜增多"而不做位置交叉分析，未触及本题核心。
3. **假设排除**：
   - ② 定型区：两侧温度全程对称平稳 → 排除；
   - ③ 轨道设定：`TDO轨道宽度设定` 列恒 6330 未动 → 排除（宽度收窄是**结果**不是原因）；
   - ④ 牵引机械：张力波动与温度异常**同时起步**且随温度稳定后趋稳，机械磨损应单向渐进 → 排除。
4. **幅度一致**：出口宽度收窄 ~9mm ≈ 与南侧 -10℃ 对应的拉伸比差异量级（机理自洽即可，不要求精确计算）。

## 期望决策要点

- **驳回"加宽轨道设定补偿"**：治标且引入新风险——宽度设定加大后实际宽度虽回 6330，但两侧拉伸比失衡仍在，操作侧边部应力集中未消除（破膜继续），且恢复供热后会出现**真实超宽**（公差 +10mm 可能触发客户投诉）；轨道是尺寸基准，不允许跟随故障漂移。
- **正确措施**：停机检查南侧拉伸区风门执行器/加热管组（对照北侧）；恢复后以「南北温差 ≤2℃」+「出口宽度回 6329±5」+「破膜回落基线」三项作为恢复验证判据。
- **过渡期**（若检修需等窗口）：限制线速、加密边部巡检，明确"临时补偿仅限宽度监控口径，不动轨道设定"。

## 常见错误（扣分点）

- 建议加宽轨道设定（未识别反补偿风险）——本题最大扣分点；
- 只分析平均温度不做南北对称性对比；
- 没有把破膜位置（qc 表类别列）与温度异常侧做交叉验证；
- 时间线缺失（未证明温度异常先于质量异常）。
