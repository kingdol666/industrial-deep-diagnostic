# BC1 评分参考（出题人用）

## 真相

**DETERMINED：干燥系统再生能力失效**（再生加热器老化 → 露点劣化 → 水分带入熔体 → 水解/汽化 → 晶点与雾度上升）。置信度应 ≥90%，证据等级 L3（DCS 统计 + 化验数据交叉验证）。

## 注入的根因链（时间线）

| 时间 | 事件 | 数据依据 |
|---|---|---|
| 09-05 18:00 | 再生加热器老化开始：再生风温 175→118℃ 阶梯下滑；露点 -60℃ 起缓升 | `dcs_…10min.csv` 再生风温度 / 干燥塔露点温度列 |
| 09-06 ~09:00 | 露点越过 -52℃，PET 含水率开始爬升（滞后 2~4 h） | `lab_…4h.csv` PET含水率(ppm) |
| 09-07 白班 | 含水率 >80 ppm，雾度越过 3.0 内控限（滞后 8~12 h），晶点同步增多 | lab 雾度 / 晶点数 |
| 09-07 起 | 熔体压力波动 std 0.55→~1.4、挤出机电流缓降 ~5A（水解降粘） | dcs 熔体压力 / 挤出机电流 |

生成参数见 `generation_manifest.json`（seed=101，事件 F1/F2/F3）。

## 关键判据（评分点）

1. **设备侧铁证**：再生风温与露点**同步**异常，而干燥风温/预结晶温度正常 → 故障定位于再生支路，不是进风或料仓问题。
2. **时滞链**：露点↑ →（2~4h）→ 含水率↑ →（8~12h）→ 雾度/晶点↑。滞后互相关（lag-compensated CCF）应在上述滞后处取峰值。
3. **假设排除**：
   - ② 挤出温度：主挤计量段温度全程 282±0.3℃ 平稳 → 排除；
   - ③ 原料批次：故障在窗口中段渐起而批次未变 → 排除（如有批次化验单可补强）；
   - ④ 铸片冷却：铸片辊温度平稳、雾度上升形态与"结晶偏大"的缓变轮廓不符 → 排除。
4. **机理一致**：水分在熔体中水解降粘 → 电流微降 + 压力波动增大，与数据吻合（四反猜测条件之"物理机制"）。

## 期望决策要点

- **立即**：停用该干燥塔再生加热器检查/更换（或切换备用干燥塔）；露点恢复 -50℃ 以下前，降线速或隔离受影响卷号。
- **短期**：对 09-06 以来入库卷加严复检雾度/晶点，投诉批次追溯；临时加密露点/含水化验至 2h 一次。
- **长期**：再生加热器电流/再生风温纳入 SPC 监控并设下限报警（再生风温 <160℃ 告警），露点 >-48℃ 预警。
- **补测**：再生加热器三相电流与阻值、干燥塔切塔记录、原料批次水分复测。

## 常见错误（扣分点）

- 只看雾度曲线而未建立**时滞因果**（把相关当时序）；
- 被主挤温度"282 正常"带偏去查挤出；
- 忽略再生风温这一设备侧证据，仅凭"露点上升"泛泛归因"干燥系统"而无定位到再生支路；
- 建议里没有追溯/复检已产出品的处置。
