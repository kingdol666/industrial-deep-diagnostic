第 1 步 · 环境准备：四个依赖一次查完
缺任何一项，启动都会直接失败 —— 所以先花 30 秒把版本查清楚
本机真实输出
① 版本下限
Node.js ≥ 18（推荐 22+）、npm ≥ 9、Python ≥ 3.10；uv 是推荐的，不装也能跑。
低一个主版本通常也能跑
② 依赖是自动装的
启动时如果缺 node_modules，后端与前端会自己 npm install；RAG 会自建 Python 虚拟环境。
所以你不用手动装一堆包
③ 网络慢的时候
RAG 的 Python 依赖体积较大。可以先切到国内镜像源再启动，免得卡在 uv sync 上。
UV_INDEX_URL 指向清华镜像
