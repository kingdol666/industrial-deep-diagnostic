命令速查卡：需要时直接翻这一页

日常运维
ind-diag start --all --detach
ind-diag status
ind-diag restart --all --detach
ind-diag stop --all
健康检查
curl http://localhost:3210/api/health
curl -I http://localhost:5180
curl -I http://localhost:8764/docs
三条都通，说明三个服务都活着
没装全局命令时
node commands/cli.mjs status
node commands/cli.mjs start --all --detach
效果和 ind-diag 完全一样，只是多打几个字；想省事就再跑一次 npm link
出问题时先看日志
.runtime/backend.log
.runtime/frontend.log
.runtime/rag.log
三个服务的日志都在这一个目录下
