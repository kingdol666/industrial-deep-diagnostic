第 1 章 · 三步起飞：克隆 → 启动 → 验证
两条命令装好，一条命令起飞；首次启动会自动补齐所有依赖
命令逐字可用
① 克隆并安装
git clone 拉下仓库，npm install 装根依赖，npm link 注册全局命令 ind-diag。
不想 link：node commands/cli.mjs
② 一键启动全部服务
--all 拉起后端、前端、RAG 三个服务；--detach 让它后台常驻并立刻返回。
必须带 --detach
不加 --detach 会怎样？
前台模式会一直阻塞，120 秒后打印 FATAL: Service manager timeout —— 服务其实已经起来了，只是命令不返回，很容易被误判为失败。
