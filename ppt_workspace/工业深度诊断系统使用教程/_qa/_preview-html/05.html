四个依赖的下限
Node.js ≥ 18（推荐 22+）
npm ≥ 9
Python ≥ 3.10
uv（推荐；缺失时回退系统 pip）
依赖是自动装的：后端/前端会自动 npm install，RAG 会自建虚拟环境
① 检查命令
四条命令分别对应四个依赖，回车即可。输出与左图一致就说明环境没问题。
node --version / npm --version
② 版本不达标怎么办
Node 用 nvm 切版本，Python 用官网安装包；uv 是可选项，不装也能跑（走 pip）。
先解决依赖，再看下一章
③ 网络慢的时候
RAG 引擎的 Python 依赖体积较大，国内网络可以先切到镜像源再启动，避免卡在 uv sync。
UV_INDEX_URL=清华镜像
