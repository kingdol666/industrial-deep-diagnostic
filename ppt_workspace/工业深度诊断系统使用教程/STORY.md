# STORY.md — 工业深度诊断系统 · 从零到投产完整教程

## 一句话主张

> 一台装好 Node 与 Python 的电脑，**三个命令**就能把工业数据变成一份可追溯、可审计的中文根因报告 ——
> 这份教程把每一步的真实界面截下来，标好号，照着点就行。

## 受众与场景

| 项 | 内容 |
|:--|:--|
| 受众 | 第一次接触本系统的工艺工程师 / 数据分析师 / 交付工程师；会看命令行、但没用过这个系统 |
| 前置 | 电脑上能装 Node 与 Python；手上有 CSV/Excel 之类的工业数据 |
| 场合 | 内部上手培训、交付前自测、新同事 onboarding |
| 目标 | 看完能独立完成：装起来 → 跑起来 → 出报告 → 看懂报告 → 出错会查 |
