# IDD 产线共享与按需记忆服务设计

基线：`251aeaf`。本文描述拟实施的设计，不代表当前分支已实现。

## 目标

先创建产线，再从该产线创建不同数据和分析类型的作业；诊断与 RSI 学习写回按产线隔离。用户可发布可审查、可撤回的经验和记忆资产，也可单独分享指定数据集。Agent 在分析中按需要检索，而不是每次启动时收到历史正文。

## 实现选择

- **一个领域服务，两个入口。** `knowledge.service.mjs` 作为查询和授权真源；HTTP 提供控制台与集成 API；引擎适配层把同一个服务暴露为只读工具。无需另部署向量服务，也不依赖本机之外的 MCP bridge。不同协议不得拥有不同授权规则。
- **按需检索优先于启动全量注入。** 启动只提供使用规则与工具可用性，不包含记忆正文、来源目录、通用令牌。首次上线至少验收一个可原生接入工具的真实引擎；其它引擎逐个验证，不以自动注入作为回退。显式依赖知识工具的任务用不支持的引擎时返回 `409 KNOWLEDGE_UNAVAILABLE_ON_HARNESS`；明确选 `disabled` 的任务可继续诊断。
- **共享发布资产，保留私有原件。** 直接共享整条线上存储目录会把脱敏、撤权、来源版本和数据权限混为一谈；因此逐项发布经过审核的快照。第一版用 SQLite + 可重建的 FTS 索引，结构化字段优先，不调用外部 embedding。

## 数据与治理

| 对象 | 合约 |
|---|---|
| 产线 | `line_id` 由服务生成且不可变；名称、别名是展示字段。同一用户可管理多条同名线。`read`、`run`、`manage` 独立判断；公共资产可读不授予产线或成员表访问。 |
| 作业 | 新产线作业持久化 `line_id` 和不可变 `knowledge_policy`（`mode: on_demand \| disabled`、`own_line: boolean`、最多 8 个明确的资产版本引用）。保持现有 start/execute 与对外 analyze 契约。未绑定旧作业可继续查看，不自动参加复用。 |
| 迁移 | 旧仓库以只读方式生成待核对清单；管理员明确确认 `run_id → line_id`。历史别名、工件显示的 line_id 只能作为建议；未知、冲突、归属不明不自动归并。绑定与修正留审计；进行中的作业禁止改线。 |
| 私有线内记忆 | 保留原始 `findings.jsonl` 和人工复核修订作为历史证据。将有效且经授权的已绑定结果生成可重建的 SQLite 查询投影；每条记录有真实来源 `run_id`、`line_id`、完成修订。先按权限、产线、状态及证据来源筛选再聚合。旧的全局浏览与编辑仅保留管理员治理入口，不作为按需查询授权。 |
| 发布与授权 | `experience`、`memory_excerpt`、`dataset` 各自独立版本；默认私有；可向指定用户授予读取/复用，或发布到站内已认证用户目录。目录可见不授予 `reuse` 或 `analyze`，也不授予原始报告、工件、源运行或原数据的读权。可撤回版本或授权，发布行为经授权人员显式确认并记审计。 |
| 数据集 | 仅针对经过审核的脱敏版本公开；存不可变对象引用、sha256、字段说明和使用限制。读、下载、作为对照分析分别授权；仅在作业显式选为对照且二次授权成功时由服务受控物化。模型提示词、经验工具响应不返回行数据、私有路径或文件下载凭据。 |

共有基础约束：Node 24 / Express / Vue 3 / SQLite；新迁移 append-only；不修改历史原报告或诊断证据；不自动跨线、不自动公开、不发送真实现场数据到未批准的模型；任何无授权或来源不明输入都不进入检索或运行。共享不是跨线共识投票：借用的内容始终是历史先验，验证后的**本线独立观测**才能回流本线 RSI；不能自动重发布引用的资产。

## HTTP 与 Agent 工具

HTTP 使用现有会话或 API token；授权以经过认证的身份与其成员/授权范围为准。以下路径是新合约：

| 路径 | 合约 |
|---|---|
| `POST /api/lines`；`GET /api/lines`；`PATCH /api/lines/:lineId` | 创建、枚举有权访问的产线、修改展示元数据；别名重名不改变边界。 |
| `PUT /api/lines/:lineId/members/:userId`；`DELETE` 同路径 | 管理明确成员授权；只有产线 manage 角色可执行。 |
| `POST /api/lines/:lineId/assets`；`POST /api/knowledge/assets/:assetId/versions` | 创建草稿资产和新版本；以人类会话和明确版本为发布前提。 |
| `POST /api/knowledge/assets/:assetId/versions/:version/publish`；`POST …/withdraw`；`PUT/DELETE …/grants/:userId` | 以站内目录或指定授权共享；更改可见范围和撤回与审计同事务。 |
| `GET /api/knowledge/catalog` | 返回调用者可发现的已发布版本，支持类型、关键词、分页，仅安全元数据；不泄露私有发布数。 |
| `POST /api/diagnosis/start`；`POST /api/external/v1/analyze` | 对产线作业接受 `lineId`、`knowledgePolicy`，校验目标线可运行、引用可复用；外部 API 不用临时文本或文件路径替代版本引用。 |
| `POST /api/knowledge/runs/:runId/search`；`GET /api/knowledge/runs/:runId/items/:refId` | 有权的用户或外部服务可查询该运行允许的来源范围；可在 pending 做明确标记的预览。独立只读浏览者不能借一项旧作业绕过自身权限。`refId` 由服务生成，详情仍校验权限，不接受任意路径或来源 ID。 |
| `GET /api/knowledge/runs/:runId/retrievals` | 有权查看该运行者查看已返回引用的摘要与来源版本、时刻、结果数量；不默认记录完整查询文本或正文。 |

工具是 `memory_search({query, signals?, limit?})`、`memory_get({ref_id})`；宿主从服务端闭包传入 `runId`、执行尝试 ID 和实际主体，不读取模型提供的 `lineId`、用户 ID 或授权声明。字段与错误映射同 HTTP；返回来源引用、类型（本线人工、本线自动、跨线发布）、概要、适用条件、证据等级及人审状态。工具结果是数据，不是工具指令。外部 MCP 若后续部署，使用服务器验证的现有身份与 `runId` 对应权限，且永不向 Agent 发用户长效 token。未认证返回 401；未知来源与不可见资源均返回 404；可见但策略不能复用用可解释错误；不可命中时结果为空并提示不扩大来源。

## 运行时

1. 创建任务时验证引用，持久化明确版本，允许预览候选；排队期间不冻结权限。
2. 启动时重验可运行权限与启用的引用；预先明确授权被撤回时该任务停止启用受影响来源并返回结构化拒绝，不替换成新版本或扩大范围。运行已启动后，每一次 search/get 都再次检查，在读取/审计同一授权边界下执行。真实 resume 必须经引擎验证可重新注册并重新授权，否则不提供工具，已明确需要的恢复路径拒绝。已返回给 Agent 的内容不可撤回；后续调用拒绝，审计保留引用元数据。
3. Agent 仅在需要排查某个信号、机制、约束或行动效果时调用。Claude SDK 第一阶段以 `tool()`、`createSdkMcpServer()` 和 `query({ options: { mcpServers } })` 接入内存中的服务适配器；CLI 不共享这个 SDK 实例，必须另行验证与声明能力。SQL 先筛选可访问的本线和显式资产版本，后执行归一化搜索与排名；不得用全局排序分数泄露未授权来源。中文优先结构化字段和 SQLite FTS5 trigram；两字关键词等用权限内、参数化的短词匹配。`limit` 默认 5、最大 10，摘要最大 240 字、详情最大 1600 字、每次执行尝试最多 20 次调用；不按关键词命中时不扩权兜底。
4. 诊断报告引用 `ref_id` 和来源版本，说明读了什么、是否适用、用本次数据如何验证；外线经验不直接提高证据等级，不确定时如实标注。可复用经验是 L5，不是机器控制指令。
5. 索引由本线来源及来源版本构建，同一 `run_id` 重复回写幂等；续跑后失效的人审重新确认前不可作为已确认参考。标无效、撤回或禁用复用的来源不得再经自动条目旁路进入新检索。必须保存本线观察与外部引用的区别；不能从 Agent 自由文本授予发布或产线成员权限。

## 安全边界与发布闸门

API 授权只能约束通过 API/tool 的访问。宿主 harness 若仍能从共享仓库工作目录或环境变量读取其他线文件、数据库或长效凭据，不能宣称实现了端到端租户隔离。共享场景上线前必须验证隔离运行目录、出站与文件访问策略及日志范围；在该引擎未验证时，只允许受信单租户开发或禁用该引擎的跨线共享功能。隔离强度按引擎逐项记录；项目里有 MCP 依赖不等于已有可用服务。工具不把内部路径、凭据或其它线的数据带入执行事件或报告。

## 验收出口

- 两个同名产线：本线查询互不可见；显式发布 B 线资产后只有选中且被授权的 A 线作业可查；他人未授权、撤回、伪造引用、待绑定旧历史均不可查。
- 私有发现、未确认/无效经验、复核撤销、重跑过期和过时版本规则均通过 HTTP 与真实检索服务的断言；公开经验不解锁原始数据。
- 真浏览器：创建两条线、分别上传样例、创建作业、发布和选用、预览与来源审计、撤回后界面与后台一致；不使用生产数据库。
- 真工具链：抓取启动提示词证明没有历史内容；运行中搜索后才出现经过授权的结果；无需历史的空白对照任务不调工具。至少一个真实引擎做现场式样例；若运行凭据/预算阻塞，分开报告传输契约测试和真实模型验收，不签无条件发布。
- 最终交付运行命令、脚本日志、测试数量、API 示例、截图和各引擎兼容矩阵。
